Sistema de entradas y salidas

El sistema es una solución integral para la administración de personal y control de asistencia. Facilita el registro de jornadas laborales y automatiza el cálculo de nóminas según las horas trabajadas. Incluye herramientas ágiles para la gestión de la plantilla, asignación de salarios por cargo y un completo historial de registros, garantizando trazabilidad, cumplimiento normativo y una drástica reducción en el tiempo dedicado a tareas administrativas.

  • Laravel
  • Php
  • JavaScript

Sistema de registro de huespedes

El sistema optimiza la recepción y administración de huéspedes mediante un panel de control intuitivo que permite gestionar check-ins, extender estancias y administrar pagos o cargos extras con total agilidad. Diseñado para adaptarse a cualquier escenario, incluye un modo de operación offline que asegura que el hotel pueda seguir trabajando sin interrupciones ante fallos de red, sincronizando los datos de forma automática y segura en cuanto se recupera la conexión.

  • JavaScript
  • Node.js
  • SQLite
